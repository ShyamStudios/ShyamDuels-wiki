Dialog Menus

ShyamDuels can show its menus as Minecraft dialogs (Paper 1.21.7+): text, links, hover tooltips, checkboxes and sliders instead of chest inventories.

Turning dialogs on

In config.yml:

gui:
  # NORMAL = chest inventories, DIALOG = dialogs
  mode: DIALOG
  # The settings menu can use its own mode
  settings-mode: DIALOG

Dialog texts and layout live in plugins/ShyamDuels/dialog-menus/*.yml, one file per menu. Missing keys fall back to the built-in defaults, so an older file keeps working after an update. Bedrock players (Floodgate) get the same menus without sprite icons and player heads.

Navigation

A menu opened from another menu gets a Back button that returns to the previous page, keeping its tab and page. Esc closes everything.

# dialog-menus/navigation.yml
dialog-navigation:
  back: "<#AAAAAA>« Back"
  back-width: 120
  # How many menus Back can step through.
  max-depth: 8

Queue

  • Tabs for Favourites, All Kits and each kit category, and a Ranked / Unranked switch. It opens on Unranked for new players and then remembers the last choice.
  • Each kit row shows the players queued; click to join or leave. Queue All joins every kit in the tab; Keep Queuing puts the player back in their queues after each match.
  • Hover texts: the kit description, the kit icon (tier, points, queue size) and, in Ranked with tiers on, a progress bar whose hover gives the next step towards a tier test.
  • When a tier test is ready, a ⚔ Tier Test button appears next to the bar. Clicking the kit opens the tier test prompt instead (see Tier tests). While in the test queue, the menu shows the test status and a row to leave it.
  • Ranked is 1v1 only. Custom kits stay out of Ranked unless dialog-queue-menu.custom-kits-in-ranked: true.

Duel request flow

/duel without a name opens a player search with up to 9 online suggestions. After picking a kit, an options page shows both players' tier or rank and a rounds slider. A confirmation appears after sending, with a "Don't show again" button.

FFA arenas

A header with the number of arenas and players fighting (hover for your kill streak), then one row per arena: icon, kit description, players fighting, the next reset and the current streak leader. Hovering a row lists the top streaks inside with player heads. Text: dialog-ffa-arenas in dialog-menus/ffa.yml.

Custom kits

In the Unranked queue, Custom kits › opens one page for the chosen team size:

  • Your kits: click a kit to host it (whoever joins plays your kit); [Manage] opens the kit page. Empty slots open the kit editor.
  • Hosted by others: kits other players are hosting for that team size; click to join.

The kit page has Host buttons for each team size, Edit items (the inventory editor) and Settings: checkboxes for building, crafting, anvils and enchanting and a Best-of slider, saved on Back or Done. Text: dialog-menus/custom-kits.yml. Hide the link with dialog-queue-menu.custom-kits-in-unranked: false in dialog-menus/queue.yml (custom-kits-in-ranked shows it in Ranked), or turn custom kits off with modules.custom-kits: false.

Settings

A page of category buttons (Gameplay, Chat, Social, Display, World) and a search box. Each category, and each search, opens a page of checkboxes and option pickers. Changes save on Back or Done; Esc discards them. See Player Settings.

Tiers

The kit list, a page per kit with the five readiness bars (hover a bar for how to raise it, click it for a page on what it shows and why), the tier test prompt and the leaderboard with kit tabs, search and country and client filters. See Tiers.

Kit and category descriptions

Hover texts for kits and categories come from dialog-menus/kit-info.yml. A kit or category left out uses the lore already set on its icon item, so most servers need no setup.

kit-info:
  kits:
    sword: "<#AAAAAA>Diamond sword and armour. No shields."
  categories:
    weapons: "<#AAAAAA>Melee kits built around one weapon."

Texts of the other menus

The party (including the team split roster and privacy names), spectate, profile, tournament, country, kit selector and kit editor dialogs, the search box and the shared Back, Close, Previous and Next buttons read their titles, buttons, tooltips and empty-state lines from dialog-menus/menu-texts.yml (section dialog-texts). The file is created on first start; delete a line to get the default back. Keys added in later versions work without being in your file; copy them from the bundled file to change them. The dialog title style is dialog-texts.common.title and title-with-subtitle.

dialog-texts:
  common:
    back: "<color:#37F699>Back</color>"
    page: "<gray>Page <page> of <pages></gray>"
  party-manage:
    ffa-tooltip: "<gray>Free-for-all match with party members</gray>"

Player preferences

Favourites, the last Ranked / Unranked choice, Keep Queuing and "Don't show again" are stored per player in the database table player_preferences, so they follow the player across servers that share the database.

Pause menu links

Separate from dialogs: pause-links in config.yml adds buttons to the client's pause menu under Server Links. See Configuration.
