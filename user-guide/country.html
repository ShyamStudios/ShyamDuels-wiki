Country Flags

Let players wear their nation's flag as a head cosmetic. ShyamDuels bundles player-head textures for every country below.

Commands

/countryflags              # Opens the flag selection GUI
/countryflags <country>    # Selects by full name or ISO code
/countryflags reset        # Resets to the default head
/flags flag <country>      # Alias syntax

All aliases (/countryflags, /countryflag, /flags, /country) require the shyamduels.country permission (default: all players). Selections persist per player and can be displayed in tab lists, scoreboards, and duels via the Country placeholders.
