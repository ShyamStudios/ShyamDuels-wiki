Credits & Licenses

ShyamDuels is built on top of several excellent open-source libraries. This page lists them along with their licenses and attribution, as required by those licenses.

Bundled Libraries

The following libraries are shaded (bundled) directly inside ShyamDuels.jar. Each is distributed under a permissive open-source license, and the full license texts are included with the plugin download.

Library Author License Role in Plugin
FastInv MrMicky MIT Lightweight inventory GUI framework powering the duel, queue, FFA, and kit menus.
FastBoard MrMicky MIT Flicker-free scoreboard rendering.
Aikar's Command Framework (ACF) Aikar MIT Command parsing, completion, and routing.
SignGUI rapha149 MIT Sign-based text input prompts (e.g. custom party size).
bStats Bastian Oppermann MIT Anonymous plugin usage metrics.
Gson Google Apache-2.0 JSON serialization for data storage and share codes.

Downloaded at Runtime

These libraries are not shipped inside the JAR. They are fetched automatically from Maven Central by Paper's built-in library loader (declared under libraries: in plugin.yml) the first time the plugin starts, so an internet connection is required on first launch.

Library License Role in Plugin
Caffeine Apache-2.0 High-performance in-memory caching.
SQLite JDBC (org.xerial) Apache-2.0 Default single-server storage backend.
MySQL Connector/J GPL-2.0 (with FOSS Exception) Optional MySQL storage backend for networks.

Required Server Plugins

These must be installed separately on the server. They are neither shaded nor downloaded by ShyamDuels, and remain entirely under their own licenses.

Dependency Role
Paper Server core (also provides Adventure / MiniMessage at runtime).
PlaceholderAPI Placeholder resolution for scoreboards, tab, and chat.
LuckPerms Permissions, VIP tiers, and party size nodes.
packetevents Packet-driven scoreboards, tab lists, and nametags.
FastAsyncWorldEdit Arena schematic capture and instant rollback.

The runtime-downloaded libraries are fetched by the end user's server at launch and are not redistributed by ShyamDuels.
