Events Reference

Custom Bukkit events fired by ShyamDuels during match setups, player deaths, and round transitions.

Event Listening Setup

Implement the standard Bukkit Listener interface and register it inside your plugin's onEnable block:

javaimport org.bukkit.event.EventHandler;
import org.bukkit.event.Listener;
import com.shyamstudio.shyamduels.duel.event.DuelStartEvent;

public class MatchListener implements Listener {

    @EventHandler
    public void onDuelStart(DuelStartEvent event) {
        // Event logic here
    }
}

Available Custom Events

Tournament Events

Package: com.shyamstudio.shyamduels.tournament.event.*. All events below extend the abstract TournamentEvent base class, which exposes getTournament() returning the associated Tournament instance.

EventFired When
TournamentCreatedEventA new tournament announcement/registration begins.
TournamentPlayerJoinEventA player registers for the tournament (Cancellable).
TournamentPlayerLeaveEventA player unregisters from the tournament.
TournamentStartedEventThe countdown finishes and the bracket is generated.
TournamentRoundStartEventA tournament round begins.
TournamentMatchStartEventA duel match begins within the bracket.
TournamentMatchEndEventA match completes with a winner and loser.
TournamentPlayerEliminatedEventA participant is eliminated from the bracket.
TournamentEndEventThe tournament concludes with a champion.
TournamentCancelledEventThe tournament is stopped or cancelled.

TournamentPlayerJoinEvent is cancellable - cancelling prevents the player from joining. Note: the manager silently returns false on cancel (no automatic message is sent).

PlayerCountryChangeEvent

Class path: com.shyamstudio.shyamduels.api.country.event.PlayerCountryChangeEvent
Fired on the main thread after a player's country flag is changed but before display refresh. Not cancellable; informational.

  • getPlayerId(): Owner UUID.
  • getPlayer(): Online Player or null if offline.
  • getOldCountry() / getNewCountry(): ISO codes (UNKNOWN when cleared).
  • getCause(): SELECT (menu/command), RESET, GEOIP (MaxMind), JOIN_RESOLVE.
  • isManual(): True for player-chosen flags; false for automatic GeoIP resolves.

DuelCountdownStartEvent

Class path: com.shyamstudio.shyamduels.duel.event.DuelCountdownStartEvent
Fired when a duel countdown begins, before PvP damage is enabled.

  • getDuel(): Returns the active Duel model.

DuelStartEvent

Class path: com.shyamstudio.shyamduels.duel.event.DuelStartEvent
Fired when a 1v1 duel starts, immediately after the countdown finishes and PvP damage is enabled. (Team duels fire PartyVsPartyStartEvent instead - DuelStartEvent is not fired for team sizes > 1.)

  • getDuel(): Returns the active Duel model.

DuelEndEvent

Class path: com.shyamstudio.shyamduels.duel.event.DuelEndEvent
Fired when a duel match terminates (due to victory conditions, player forfeit, or admin termination commands). Team matches additionally fire their party-end variant (PartyVsPartyEndEvent, PartySplitEndEvent, or PartyFFAEndEvent) from the same finish path.

  • getDuel(): Returns the concluded Duel model. Use the model to check final state, winner teams, and ELO calculations.

FightDeathEvent

Class path: com.shyamstudio.shyamduels.duel.event.FightDeathEvent
Fired when a player dies inside a match arena during a duel round.

  • getPlayer(): Returns the victim player entity.
  • getKiller(): Returns the killer player entity (returns null if death was caused by environment, fall damage, or potion effect).
  • getDuel(): Returns the active Duel model.
  • isFinalRound(): Returns true if this death concludes the entire match (meaning no further rounds will execute).

PlayerVirtualDeathEvent

Class path: com.shyamstudio.shyamduels.api.event.PlayerVirtualDeathEvent
Fired when a player experiences virtual death (e.g. during a duel match where damage is cancelled to bypass the standard death/respawn screen). Ideal for custom kill effects, cosmetics, or custom stats trackers.

  • getPlayer(): Returns the victim player entity.
  • getKiller(): Returns the killer player entity, if one exists (returns null if death was caused by environment or fall damage).
  • getLocation(): Returns the Location where the virtual death occurred.
  • getDamageCause(): Returns the Bukkit DamageCause that triggered the death (returns null if unknown).
  • getDuel(): Returns the active Duel model in which the player died (returns null if not in a duel).

MatchRecordedEvent

Class path: com.shyamstudio.shyamduels.api.event.history.MatchRecordedEvent (API 2.1)
Fired on the main thread when a finished match has been recorded, just before it is written to the database. Use it to push results to a website or Discord without polling.

  • getRecord(): The MatchRecord, including every player's saved inventory.

Tier Events

Package com.shyamstudio.shyamduels.api.event.tier. All fire on the main thread and only while tiers are enabled.

  • TierChangeEvent: a player's tier in a kit changed. getPlayerId(), getKit(), getPreviousTier(), getNewTier() (tier index, -1 = unranked), getNewTierName(), isPromotion() and getReason(): TEST_PASSED, TEST_PLACED (a lost test that still raised the tier through skill placement), ADMIN, INACTIVITY, LOSSES, RESET.
  • TierTestStartEvent: a tier test match started. getDuelId(), getKit(), getChallengers() (one or two players testing) and getTester() (staff tester, or null).
  • TierTestEndEvent: fired once per challenger when a test ends. getDuelId(), getPlayerId(), getKit(), isPassed() and getTier() (the tier after the test).

Lifecycle Events (API 2.1)

Queue, party, FFA and Elo events. All fire on the main thread. Events marked cancellable fire before the change; when you cancel them the plugin sends no message, so tell the player why.

EventWhenMain getters
event.queue.QueueJoinEvent (cancellable)Before a player joins a queue (solo, party member or tier test)getPlayer(), getKitName(), getMode(), getQueueType(), isTierTest(), getPartyId()
event.queue.QueueLeaveEventFor each queue a player leavesgetPlayerId(), getPlayer(), getKitName(), getReason(): LEFT, MATCH_FOUND, DISCONNECT, RESET
event.party.PartyCreateEvent (cancellable)Before a party is createdgetOwner()
event.party.PartyJoinEvent (cancellable)Before a player joins a partygetPlayer(), getPartyId(), getOwnerId(), getCause(): INVITE, PUBLIC, REQUEST
event.party.PartyLeaveEventAfter a player left a partygetPlayerId(), getPartyId(), getReason(): LEFT, KICKED, DISCONNECT
event.party.PartyDisbandEventWhen a party is disbanded or left emptygetPartyId(), getOwnerId(), getMembers()
event.ffa.FFAJoinEvent (cancellable)Before a player enters an FFA arenagetPlayer(), getArenaName(), getKitName()
event.ffa.FFALeaveEventAfter a player left FFAgetPlayerId(), getArenaName(), isDisconnect()
event.ffa.FFAKillEventA kill in FFA, after it was countedgetKiller(), getVictim(), getArenaName(), getKillerStreak(), getVictimStreak()
event.stats.EloChangeEventAfter a ranked match changed a player's ElogetPlayerId(), getKitName(), isWon(), getOldElo(), getNewElo(), getChange(), getKitChange()

All classes are in com.shyamstudio.shyamduels.api.event. Check api.metadata().supports("lifecycle-events") before relying on them.

RoundStartEvent

Class path: com.shyamstudio.shyamduels.duel.event.RoundStartEvent
Fired at the moment a round begins in multi-round duels (e.g. Best of 3 matches), after the round's countdown finishes and the fight starts (rounds 2+).

  • getDuel(): Returns the active Duel model.

RoundEndEvent

Class path: com.shyamstudio.shyamduels.duel.event.RoundEndEvent
Fired immediately after a round concludes (a player or team dies), before players are reset for the next round.

  • getDuel(): Returns the active Duel model.

Party Match Events

Event Class Trigger Condition Key Methods
PartyFFAStartEvent Fired when a party Free-For-All match begins. getDuel()
PartyFFAEndEvent Fired when a party Free-For-All match concludes. getDuel()
PartySplitStartEvent Fired when a party split team battle starts. getDuel()
PartySplitEndEvent Fired when a party split team battle ends. getDuel()
PartyVsPartyStartEvent Fired when a vs-party challenge duel starts. getDuel()
PartyVsPartyEndEvent Fired when a vs-party challenge duel concludes. getDuel()

AdvancementGrantEvent

Class path: com.shyamstudio.shyamduels.advancement.event.AdvancementGrantEvent
Fired on the main thread when a player completes an advancement. Informational and not cancellable.

  • getPlayer(): Returns the player who earned the advancement.
  • getAdvancement(): Returns the completed advancement definition.

Full Example: Tracking Match Results

A complete listener that registers in onEnable and reacts to several ShyamDuels events. It records a kill via the API on each fight death and announces the winner when a duel ends:

javaimport com.shyamstudio.shyamduels.api.ShyamDuelsAPI;
import com.shyamstudio.shyamduels.api.ShyamDuelsProvider;
import com.shyamstudio.shyamduels.duel.Duel;
import com.shyamstudio.shyamduels.duel.event.DuelEndEvent;
import com.shyamstudio.shyamduels.duel.event.DuelStartEvent;
import com.shyamstudio.shyamduels.duel.event.FightDeathEvent;
import com.shyamstudio.shyamduels.duel.event.RoundStartEvent;
import org.bukkit.Bukkit;
import org.bukkit.entity.Player;
import org.bukkit.event.EventHandler;
import org.bukkit.event.Listener;
import org.bukkit.plugin.java.JavaPlugin;

public class MatchTracker implements Listener {

    private final JavaPlugin plugin;

    public MatchTracker(JavaPlugin plugin) {
        this.plugin = plugin;
        Bukkit.getPluginManager().registerEvents(this, plugin);
    }

    @EventHandler
    public void onDuelStart(DuelStartEvent event) {
        Duel duel = event.getDuel();
        plugin.getLogger().info("Duel started on arena " + duel.getArena().getName());
    }

    @EventHandler
    public void onRoundStart(RoundStartEvent event) {
        plugin.getLogger().info("New round started.");
    }

    @EventHandler
    public void onFightDeath(FightDeathEvent event) {
        Player victim = event.getPlayer();
        Player killer = event.getKiller();
        if (killer != null) {
            ShyamDuelsAPI api = ShyamDuelsProvider.get();
            if (api != null) {
                api.stats().recordKill(killer, victim);
                killer.sendMessage("§aYou eliminated " + victim.getName()
                        + " §7(kills: " + api.stats().getKills(killer.getUniqueId()) + ")");
            }
        }
        if (event.isFinalRound()) {
            victim.sendMessage("§cYou lost the match.");
        }
    }

    @EventHandler
    public void onDuelEnd(DuelEndEvent event) {
        Duel duel = event.getDuel();
        plugin.getLogger().info("Duel ended (kit: "
                + (duel.getKit() != null ? duel.getKit().getName() : "unknown") + ").");
    }
}
